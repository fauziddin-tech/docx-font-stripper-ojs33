Plugin generik OJS 3.3.0-x (dikembangkan terhadap 3.3.0-22, PHP 7.4–8.2) yang membuang **font tertanam** dari file Word `.docx` saat diunggah, dan **memperkecil gambar PNG** yang resolusinya jauh di atas ukuran tampilnya.

### Unduh dan pasang

Unduh **`docxFontStripper-1.1.0.0.tar.gz`** di bawah (jangan ganti namanya), lalu di OJS: *Pengaturan → Website → Plugin → Unggah Plugin Baru*. Aktifkan per jurnal di daftar Plugin Terpasang.

Kebutuhan: ekstensi PHP `zip` dan `dom` (wajib), `gd` (untuk memperkecil gambar).

### Isi rilis ini

- Saat file submission diunggah (submission, review, lampiran reviewer, revisi, copyediting, produksi, diskusi) lewat hook `SubmissionFile::add` / `SubmissionFile::edit`:
  - `word/fonts/*`, relasi font, `w:embed*` di `fontTable.xml`, entri terkait di `[Content_Types].xml`, serta `w:embedTrueTypeFonts`/`w:saveSubsetFonts` di `settings.xml` dibuang;
  - PNG yang hanya dipakai sebagai gambar biasa diperkecil ke 500 dpi pada ukuran tampil terbesarnya (nama dan format file tetap);
  - entri ZIP yang tersimpan tanpa kompresi dikompresi ulang (isi identik).
- Isi dokumen, tabel, komentar, dan track changes tidak diubah. Hasil divalidasi (ZIP konsisten, CRC setiap entri, XML valid, tidak ada relasi menggantung, bagian lain identik byte per byte); bila gagal, file asli dipertahankan. Penggantian file atomik dan izin file dipertahankan.
- File bukan `.docx` (`.doc`, `.docm`, PDF, gambar, dll.) tidak disentuh. Salinan file ke tahap lain (tanpa unggahan baru) tidak diproses.
- Setiap hasil dicatat ke error log PHP dengan awalan `[DocxFontStripper]`.

### Contoh hasil

| File | Sebelum | Sesudah |
|---|---|---|
| Artikel dengan 14 font tertanam, entri ZIP tanpa kompresi | 14,95 MB | 0,49 MB |
| Artikel dengan 22 file font + logo PNG 1493×1053 px yang tampil 1,7×1,2 cm | 10,69 MB | 0,15 MB |

### Perlu diketahui

- Tanpa font tertanam, pembaca yang tidak memiliki font aslinya melihat font pengganti: teks sama, tata letak bisa bergeser.
- Diuji dengan 28 tes PHPUnit (PHP 7.4/8.1/8.2), dua file artikel nyata (diverifikasi dengan LibreOffice dan python-docx), dan harness yang meniru alur unggah OJS 3.3. **Belum** diuji pada instalasi OJS sungguhan maupun di Microsoft Word, dan belum pada penyimpanan non-lokal.
