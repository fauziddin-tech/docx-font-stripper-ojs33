Plugin generik OJS 3.3.0-x (dikembangkan terhadap 3.3.0-22, PHP 7.4–8.2) yang membuang **font tertanam** dari file Word `.docx` saat diunggah, memperkecil **gambar PNG** yang resolusinya berlebihan, dan sejak versi ini **menolak file berbahaya** saat diunggah.

### Unduh dan pasang

Unduh **`docxFontStripper-1.2.0.0.tar.gz`** di bawah (jangan ganti namanya). Bila versi 1.1.0.0 sudah terpasang: *Pengaturan → Website → Plugin → Plugin Terpasang*, buka baris Docx Font Stripper, lalu klik **Upgrade** (hanya tampil untuk Administrator situs). Untuk pemasangan baru, gunakan *Unggah Plugin Baru*.

### Baru: penjaga gawang unggahan

OJS 3.3 menerima file berekstensi apa pun. Hanya ekstensi yang mengandung `php` yang diubah OJS menjadi `.txt`. `.phtml`, `.phar`, `.pht`, `.shtml`, `.cgi`, dan sejenisnya tersimpan apa adanya di `files_dir`, seperti `zip.phtml` yang pernah diunggah lewat akun spam.

- Ditolak saat diunggah, **sebelum disimpan**:
  - skrip server: `php`, `phtml`, `pht`, `phar`, `phps`, `php3`–`php8`, `inc`, `cgi`, `fcgi`, `asp`, `aspx`, `ashx`, `asmx`, `jsp`, `jspx`, `shtml`, `shtm`, `stm`;
  - konfigurasi server: `.htaccess`, `.htpasswd`, `.user.ini`;
  - program Windows: `exe`, `dll`, `com`, `scr`, `msi`, `bat`, `cmd`, `vbs`, `vbe`, `wsf`, `ps1`, `hta`, `lnk`.
- Berlaku di semua jalur file submission:
  - lewat **wizard unggah** (naskah, review, lampiran reviewer, revisi, copyediting, produksi/galley, diskusi): pengguna melihat pesan *"File berekstensi .phtml tidak diterima karena dapat dijalankan sebagai program di server. Unggah naskah dalam format DOCX, ODT, atau PDF."*, dan tombol Lanjutkan tetap nonaktif;
  - lewat **REST API**: respons 400, dan OJS menghapus file yang sempat tersimpan.
- Yang diperiksa ekstensi terakhir, karena hanya itu yang sampai ke disk. Huruf besar/kecil tidak berpengaruh, dan titik atau spasi di akhir nama diabaikan.
  - `zip.phtml` dan `SHELL.PHAR.` ditolak.
  - `artikel.php.docx` diterima, karena tersimpan sebagai `.docx`.
- Tidak ditolak: kode riset (`.py`, `.r`, `.sh`), `.svg`, galley HTML, `.zip`, `.csv`.
- Setiap penolakan dicatat ke error log PHP, misalnya `[DocxFontStripper] blocked upload (wizard): ext=phtml name="zip.phtml" userId=812 ip=203.0.113.5`.

Fitur pembersih font dan gambar tidak berubah dari 1.1.0.0.

### Pengujian

- 71 tes PHPUnit (43 di antaranya baru, untuk penjaga unggahan).
- Diuji pada instalasi OJS 3.3.0-22 lokal:
  - wizard menolak `zip.phtml` dengan pesan berbahasa Indonesia, sedangkan `.docx` tetap lolos;
  - REST API mengembalikan 400 untuk `.phtml` dan `.phar`, dan 200 untuk `.docx`;
  - tidak ada file sisa di `files_dir`.
