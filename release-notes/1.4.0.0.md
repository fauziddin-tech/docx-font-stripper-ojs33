Plugin generik OJS 3.3.0-x (dikembangkan terhadap 3.3.0-22, PHP 7.4–8.2) yang membuang **font tertanam** dari file Word `.docx` saat diunggah, memperkecil **gambar PNG** yang resolusinya berlebihan, menolak file berbahaya saat diunggah, dan menampilkan ukuran file. Sejak versi ini, ukuran file juga tampil **di daftar file backend**, apa pun temanya.

### Unduh dan pasang

Unduh **`docxFontStripper-1.4.0.0.tar.gz`** di bawah (jangan ganti namanya). Bila versi lama sudah terpasang: *Pengaturan → Website → Plugin → Plugin Terpasang*, buka baris Docx Font Stripper, lalu klik **Upgrade** (hanya tampil untuk Administrator situs). Untuk pemasangan baru, gunakan *Unggah Plugin Baru*.

### Baru: ukuran file di daftar file backend

Fitur ini sebelumnya ada di tema Manuscript-Daffa, sehingga hilang saat jurnal memakai tema lain. Sekarang plugin ini yang menampilkannya, dan fitur tersebut dihapus dari tema.

- Ukuran setiap file tampil di bawah jenis file, mis. "Article Text" lalu "8,0 MB", di:
  - daftar file *Workflow* (Submission, Review, Copyediting, Production);
  - *Author Dashboard*;
  - halaman reviewer (*Download & Review*), di bawah tanggal.
- File **5 MB ke atas** ditandai merah tebal. Penyebabnya sering font tertanam di Word.
- Ukuran dibaca langsung dari server tanpa mengunduh file, jadi tidak tercatat sebagai unduhan.
- Hanya pengguna yang terlibat yang melihat ukuran:
  - manajer, admin, dan editor/asisten yang ditugaskan: semua file;
  - penulis: file di dasbor penulis dan unggahannya sendiri;
  - reviewer: hanya file review-nya sendiri.

### Diperbaiki (dari 1.3.0.0)

- Filter ukuran galley di halaman pembaca sekarang didaftarkan dengan nama sendiri. Di 1.3.0.0, filter itu bisa saling menimpa dengan filter tanpa nama milik plugin lain (mis. Publication Facts Label).

Fitur pembersih font/gambar, penjaga unggahan, dan ukuran galley di halaman pembaca tidak berubah.
