Perbaikan penomoran untuk **OJS 3.5**. Fitur sama dengan 1.5.0.0.

### Unduh dan pasang

Pilih berkas sesuai versi OJS (jangan ganti namanya):

| OJS | Berkas |
|---|---|
| 3.3 (PHP 7.4–8.2) | `docxFontStripper-1.5.0.1.tar.gz` |
| 3.5 (PHP 8.2+) | `docxFontStripper-ojs3.5-2.5.0.1.tar.gz` |

- **Sudah terpasang versi lama:** *Pengaturan → Website → Plugin → Plugin Terpasang*, buka baris Docx Font Stripper, lalu klik **Upgrade**. Tombol ini hanya tampil untuk Administrator situs.
- **Pemasangan baru:** gunakan *Unggah Plugin Baru*.

### Diperbaiki

- Build OJS 3.5 sekarang bernomor **2.5.0.1**, bukan 1.5.0.0.
  - Port OJS 3.5 sebelumnya pernah dirilis sebagai 2.0.0.0, dengan fitur pembersih font dan gambar saja.
  - OJS hanya mau meng-upgrade plugin ke versi yang lebih tinggi, jadi jurnal yang sudah memasang 2.0.0.0 menolak berkas 1.5.0.0.
  - Dengan 2.5.0.1, jurnal itu bisa langsung meng-upgrade. Folder plugin lama diganti seluruhnya oleh OJS saat upgrade.
- Mulai versi ini:
  - build OJS 3.3 memakai seri **1.x**;
  - build OJS 3.5 memakai seri **2.x**;
  - angka di belakangnya sama (1.5.0.1 ↔ 2.5.0.1).
- Build OJS 3.3 tidak berubah. Nomornya ikut naik ke 1.5.0.1 supaya kedua berkas terbit dalam satu rilis.

### Yang didapat jurnal yang meng-upgrade dari 2.0.0.0

Selain pembersih font dan gambar yang sudah ada:

- **penjaga unggahan:** menolak `.php`, `.phtml`, `.phar`, `.exe`, dan sejenisnya saat diunggah;
- **ukuran file di tautan galley:** di halaman pembaca;
- **ukuran file di daftar file backend:** file 5 MB ke atas ditandai merah.
