Plugin generik OJS 3.3.0-x (dikembangkan terhadap 3.3.0-22, PHP 7.4–8.2) yang membuang **font tertanam** dari file Word `.docx` saat diunggah, memperkecil **gambar PNG** yang resolusinya berlebihan, menolak file berbahaya saat diunggah, dan sejak versi ini **menampilkan ukuran file galley** apa pun temanya.

### Unduh dan pasang

Unduh **`docxFontStripper-1.3.0.0.tar.gz`** di bawah (jangan ganti namanya). Bila versi lama sudah terpasang: *Pengaturan → Website → Plugin → Plugin Terpasang*, buka baris Docx Font Stripper, lalu klik **Upgrade** (hanya tampil untuk Administrator situs). Untuk pemasangan baru, gunakan *Unggah Plugin Baru*.

### Baru: ukuran file pada tautan galley

Sebelumnya ukuran file (mis. `PDF (1,2 MB)`) ditampilkan oleh tema Daffa Manuscript, sehingga hilang saat jurnal berganti tema. Sekarang plugin ini yang menambahkannya:

- Berlaku di semua halaman pembaca: halaman artikel, daftar isi terbitan, arsip, penampil PDF, dan galley terbitan (full issue).
- Tidak bergantung pada tema: plugin membaca HTML akhir halaman dan mengenali tautan galley dari URL-nya, bukan dari template tema.
- Tidak dobel: tautan yang sudah menampilkan ukuran (mis. tema Daffa Manuscript masih aktif) dibiarkan.
- Hanya galley yang sudah terbit di jurnal itu; galley berupa URL jarak jauh dilewati.
- Pemisah desimal mengikuti bahasa pembaca: `1,2 MB` (Indonesia), `1.2 MB` (English).
- Bisa diatur lewat CSS tema dengan kelas `.dfs_file_size`.

Fitur pembersih font/gambar dan penjaga unggahan tidak berubah dari 1.2.0.0.
