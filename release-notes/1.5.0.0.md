Docx Font Stripper sekarang tersedia untuk **OJS 3.5**, selain OJS 3.3. Fiturnya sama di kedua versi: membuang **font tertanam** dari file Word `.docx` saat diunggah, memperkecil **gambar PNG** yang resolusinya berlebihan, **menolak file berbahaya** saat diunggah, dan menampilkan **ukuran file**, baik di tautan galley halaman pembaca maupun di daftar file backend.

### Unduh dan pasang

Pilih berkas sesuai versi OJS (jangan ganti namanya):

| OJS | Berkas |
|---|---|
| 3.3 (PHP 7.4–8.2) | `docxFontStripper-1.5.0.0.tar.gz` |
| 3.5 (PHP 8.2+) | `docxFontStripper-ojs3.5-1.5.0.0.tar.gz` |

- **Pemasangan baru:** *Pengaturan → Website → Plugin → Unggah Plugin Baru*, lalu aktifkan plugin untuk jurnal.
- **Memperbarui versi lama (OJS 3.3):** klik **Upgrade** pada baris Docx Font Stripper di *Plugin Terpasang*. Tombol ini hanya tampil untuk Administrator situs.

### Baru: versi OJS 3.5

- Semua fitur versi OJS 3.3 tersedia di OJS 3.5:
  - **pembersih font dan gambar:** wizard unggah, REST API, dan unggah revisi;
  - **penjaga unggahan:** berlaku di wizard dan REST API, termasuk penggantian file (`PUT`), yang di OJS 3.5 divalidasi sebelum file disimpan;
  - **ukuran file di tautan galley:** halaman artikel, daftar isi terbitan, dan beranda;
  - **ukuran file di daftar file backend:** dasbor *Editorial* dan *Author Dashboard*, file 5 MB ke atas merah, dengan aturan akses yang sama.
- Dengan ini, jurnal OJS 3.5 yang memakai tema Manuscript-Daffa 1.0.4.0 mendapatkan kembali ukuran file di daftar file backend lewat plugin ini.

### Versi OJS 3.3

Tidak ada perubahan fitur dari 1.4.0.0. Nomor versi dinaikkan supaya kedua versi tetap sama.

### Pengujian

- 112 tes PHPUnit lolos. CI sekarang juga berjalan di PHP 8.3 dan 8.4.
- Diuji pada instalasi **OJS 3.5.0-6** lokal (PostgreSQL):
  - REST API: `.docx` berfont tertanam 558 KB menjadi 4,9 KB; `.docx` tanpa font tidak diubah; `.phtml` ditolak (400) tanpa file sisa, baik lewat `POST` maupun `PUT`.
  - Wizard unggah: `.phtml` ditolak dengan pesan dan tombol *Continue* tetap nonaktif; `.docx` dibersihkan.
  - Galley "PDF (5 KB)" tampil di halaman artikel, terbitan, dan beranda.
  - Dasbor *Editorial*: ukuran tampil di bawah jenis file; file 5,7 MB ditandai merah. Ukuran tidak diberikan kepada pengunjung yang tidak login.
